# 🚗 FareFusion — Smart Ride Fare Comparison

**Compare ride fares. Save money. Travel smarter.**

FareFusion is a web application that helps users compare estimated ride fares from Ola, Uber, and Rapido based on their pickup and destination locations. It displays estimated distance, travel time, and fare comparisons to help users choose a cost-effective ride.

## ✨ Features

- 📍 **Pickup & Destination:** Enter your starting point and destination.
- 🚕 **Multi-Provider Comparison:** Compare estimated fares from Ola, Uber, and Rapido.
- 💰 **Lowest Fare Highlight:** Identify the lowest displayed fare estimate.
- 🛣️ **Route Information:** View estimated distance and travel time.
- 🔄 **Swap Locations:** Switch pickup and destination with one click.
- 📱 **Responsive Design:** Use the application on desktop and mobile devices.
- 🎨 **Colorful Interface:** Enjoy a modern, user-friendly design.
- 💾 **Saved Routes:** Save frequently used routes, if supported by your current implementation.

## 🚀 Getting Started

### Prerequisites

- A modern web browser
- [Visual Studio Code](https://code.visualstudio.com/) (recommended)
- Live Server extension for VS Code (optional)

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/FareFusion.git
   ```

2. Open the project folder:

   ```bash
   cd FareFusion
   ```

3. Open the folder in Visual Studio Code.

4. Run the application:
   - Open `frontend/index.html` in your browser, or
   - Use the Live Server extension to launch the page.

> If your project requires a Node.js backend, environment variables, or a database, follow the corresponding setup instructions in your project files.

## 📖 How to Use

1. Open FareFusion in your browser.
2. Enter your pickup location.
3. Enter your destination.
4. Select a vehicle type, if available.
5. Click **Compare Rides**.
6. Review the displayed fare estimates, route distance, and travel time.
7. Compare the options before choosing a provider.

## ⚠️ Disclaimer

FareFusion is an independent ride fare comparison project and is not affiliated with Ola, Uber, or Rapido. Fare estimates may be illustrative or based on available data. Actual prices, availability, and travel times can vary by location, demand, traffic, and provider. Always verify the final fare in the respective provider's official application before booking.
